# 되새김 — 망각 곡선 기반 복습 알림 앱

외운 내용을 **잊어버리기 직전에** 복습하라고 알려주는 영어회화 암기 앱입니다. 안드로이드 앱(Capacitor)과 웹 앱(PWA)으로 쓸 수 있어요.
에빙하우스 망각 곡선으로 카드마다 "지금 기억하고 있을 확률"을 계산하고, 이 확률이 목표치(기본 90%)까지 떨어지는 순간에 알림을 보냅니다.

## 안드로이드 폰에 설치

GitHub에 푸시하면 **GitHub Actions**가 APK를 자동으로 만듭니다.

1. 저장소의 **Actions** 탭 → 최신 "Android APK" 실행 → 아래 **Artifacts**의 `doesaegim-apk` 내려받기
2. 압축을 풀어 나온 `app-debug.apk`를 휴대폰으로 옮겨 열기 ("출처를 알 수 없는 앱 설치" 허용 필요)
3. 앱 실행 → **설정 → 복습할 때가 되면 알림 받기** 켜기 → 알림 권한, "알람 및 리마인더" 권한 허용

직접 빌드하려면 Android Studio를 설치하고:

```bash
npm install
npm run android      # www/ 를 안드로이드 프로젝트로 복사하고 Android Studio로 열기
```

## 브라우저에서 미리 보기

```bash
npm start            # http://localhost:8000
npm test             # 스케줄러 단위 테스트 (Node 22+)
```

웹 파일(`www/`)을 고친 뒤 앱에 반영하려면 `npm run sync`를 실행합니다.

## 기본 덱과 학습 흐름

| 덱 | 개수 | 방향 |
|---|---|---|
| 회화 필수 단어 · 초급 | 500 | 영 → 한 (단어 · 품사 · 뜻 · 회화체 예문) |
| 회화 필수 단어 · 중급 | 500 | 영 → 한 (단어 300 + 구동사·관용 표현 200) |
| 회화 필수 단어 · 고급 | 500 | 영 → 한 (단어 304 + 구동사·관용 표현 196) |
| 회화 필수 문장 · 초급 | 100 | 한 → 영 (10가지 상황 × 10문장, 핵심 표현 강조) |
| 회화 필수 문장 · 중급 | 100 | 한 → 영 (직장·근황·공감·의견 조율·거절·불만·일정 변경·병원·여행 돌발·칭찬) |
| 내 카드 | – | 직접 입력 |

- **덱** 탭에서 덱을 켜면 하루 N개(기본 10개)씩 새 카드가 나오고, 켠 덱끼리 번갈아 나옵니다.
- 덱은 20장씩 **스테이지**로 나뉩니다. ★ 모두 배움(다음 스테이지 열림) · ★★ 모두 복습 간격 1일 이상 · ★★★ 1주 이상.
- 스테이지를 시작할 때 아는 카드를 한꺼번에 체크하거나, 카드마다 **이미 알아요**를 누르면 복습 없이 넘어갑니다(할당량도 쓰지 않음).
- 새 카드는 앞뒷면과 발음을 먼저 보여 주고, "외웠어요"를 누르면 망각 곡선이 시작됩니다(20분 뒤 첫 복습).
- 복습이 50개 넘게 밀리면 그날 새 카드는 쉬고, 하루치를 다 배우면 "5개 더 배우기"를 할 수 있습니다.
- 영어가 화면에 나오면 자동으로 읽어 줍니다(안드로이드 기본 TTS, 브라우저에서는 Web Speech).
- 덱 카드는 학습 기록만 저장하고 내용은 덱 파일에서 읽기 때문에, 덱을 고쳐 배포해도 기록이 유지됩니다.

### 덱 내용 고치기

원본은 `content/*.tsv`(탭 구분)입니다. 고친 뒤 덱 JSON을 다시 만드세요.

```bash
pip install wordfreq openpyxl
python3 scripts/build_decks.py --review review.xlsx   # www/decks/*.json + 검수용 엑셀
```

단어 덱은 wordfreq 빈도순으로 정렬하되, 여러 단어로 된 표현(구동사 등)은 고르게 섞습니다.
단어 선정·정렬에 [wordfreq](https://github.com/rspeer/wordfreq) 빈도 데이터(CC BY-SA 4.0)를 참고했으며, 덱 데이터도 CC BY-SA 4.0으로 배포합니다.

## 스케줄링 모델 (`scheduler.js`)

- 망각 곡선: `R(t) = e^(-t/S)` — `t`는 마지막 복습 후 경과 시간, `S`는 카드의 **기억 안정성**
- 다음 복습 시점: `R`이 목표 유지율에 닿는 때 → `t* = -S·ln(목표)`
- 복습 후 평가(다시/어려움/알맞음/쉬움)에 따라 `S`를 갱신
  - 알맞음 ×3, 어려움 ×1.4, 쉬움 ×5 (예정 시각에 복습했을 때 기준)
  - 일찍 복습하면 성장 폭이 작고, 기억이 흐려진 뒤 성공하면 더 큼 (spacing effect)
  - 다시: `S`를 30%로 줄임 (초기값 아래로는 안 내려감)
- 기본값으로 계속 "알맞음"을 고르면 간격은 **20분 → 1시간 → 3시간 → 9시간 → 1.1일 → 3.4일 → 10일 → 1개월**로,
  에빙하우스 실험의 측정 시점(20분, 1시간, 9시간, 1일, 6일, 31일)과 대략 맞습니다.

## 알림 동작

- **안드로이드 앱:** 카드가 바뀔 때마다 OS 로컬 알림을 미리 예약합니다. 앱을 완전히 꺼도 정해진 시각에 알림이 옵니다.
  10분 안에 몰린 카드는 알림 하나로 묶고, 최대 60개까지 예약합니다.
- **웹(PWA):** 탭이 열려 있을 때만 정확하고, 닫혀 있으면 Chrome/Edge 설치형에서 Periodic Background Sync로 가끔 확인합니다.
- 방해 금지 시간(기본 23시~8시)에 걸린 알림은 끝나는 시각으로 미룹니다.

## 파일 구성

- `www/index.html`, `www/styles.css`, `www/app.js` — 화면과 상호작용
- `www/scheduler.js` — 망각 곡선 계산과 알림 계획 (UI 의존성 없음, 테스트 대상)
- `www/decks.js` — 덱 조회, 하루 신규 카드 배분 (테스트 대상)
- `www/tts.js` — 발음 듣기
- `www/decks/` — 덱 데이터 (`scripts/build_decks.py`가 생성), `content/` — 덱 원본 TSV
- `www/native.js` — 안드로이드 로컬 알림 (Capacitor)
- `www/curve.js` — 카드별 망각 곡선 SVG
- `www/sw.js` — 웹용 오프라인 캐시, 백그라운드 알림
- `android/` — Capacitor 안드로이드 프로젝트, `assets/` — 아이콘 원본
- 데이터는 기기 안(`localStorage`)에 저장되며 설정 화면에서 JSON으로 내보내고 가져올 수 있습니다.
