# 되새김 — 망각 곡선 기반 복습 알림 앱

외운 내용을 **잊어버리기 직전에** 복습하라고 알려주는 PWA(웹 앱)입니다.
에빙하우스 망각 곡선으로 카드마다 "지금 기억하고 있을 확률"을 계산하고, 이 확률이 목표치(기본 90%)까지 떨어지는 순간에 알림을 보냅니다.

## 실행

```bash
npm start          # = python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. 서비스 워커와 알림은 `localhost` 또는 HTTPS에서만 동작합니다.
휴대폰에서 쓰려면 GitHub Pages 같은 HTTPS 호스팅에 올리고 "홈 화면에 추가"로 설치하세요.

```bash
npm test           # 스케줄러 단위 테스트 (Node 20+)
```

## 스케줄링 모델 (`scheduler.js`)

- 망각 곡선: `R(t) = e^(-t/S)` — `t`는 마지막 복습 후 경과 시간, `S`는 카드의 **기억 안정성**
- 다음 복습 시점: `R`이 목표 유지율에 닿는 때 → `t* = -S·ln(목표)`
- 복습 후 평가(다시/어려움/알맞음/쉬움)에 따라 `S`를 갱신
  - 알맞음 ×3, 어려움 ×1.4, 쉬움 ×5 (예정 시각에 복습했을 때 기준)
  - 일찍 복습하면 성장 폭이 작고, 기억이 흐려진 뒤 성공하면 더 큼 (spacing effect)
  - 다시: `S`를 30%로 줄임 (초기값 아래로는 안 내려감)
- 기본값으로 계속 "알맞음"을 고르면 간격은 **20분 → 1시간 → 3시간 → 9시간 → 1.1일 → 3.4일 → 10일 → 1개월**로,
  에빙하우스 실험의 측정 시점(20분, 1시간, 9시간, 1일, 6일, 31일)과 대략 맞습니다.

## 알림 동작과 한계

| 상황 | 동작 |
|---|---|
| 앱 탭이 열려 있음(백그라운드 포함) | 30초마다 확인해서, 새로 복습 시간이 된 카드가 있으면 알림 |
| 앱이 닫혀 있음 · Chrome/Edge에 설치한 PWA | Periodic Background Sync로 브라우저가 깨울 때 확인 (주기는 브라우저가 결정, 보통 수십 분~수 시간) |
| 앱이 닫혀 있음 · iOS Safari / Firefox | 알림 없음 |

방해 금지 시간(기본 23시~8시)에는 알림을 보내지 않습니다.
정확한 시각에 앱이 꺼진 상태에서도 알림을 받으려면 **Web Push 서버**를 두거나, Capacitor 등으로 감싸 **네이티브 로컬 알림**을 써야 합니다.

## 파일 구성

- `index.html`, `styles.css`, `app.js` — 화면과 상호작용
- `scheduler.js` — 망각 곡선 계산 (UI 의존성 없음, 테스트 대상)
- `curve.js` — 카드별 망각 곡선 SVG
- `sw.js` — 오프라인 캐시, 백그라운드 알림, 알림 클릭 처리
- 데이터는 브라우저 `localStorage`에 저장되며 설정 화면에서 JSON으로 내보내고 가져올 수 있습니다.
